*********GitHub 프로젝트 업로드 방법*********

1. 자기 브랜치에 프로젝트 올리기

1-1. moble2 저장소에 접속합니다.
1-2. 파일 목록 위쪽의 브랜치 버튼을 누릅니다.
1-3. 자기 이름 브랜치를 선택합니다.
1-4. + 버튼을 누릅니다.
1-5. Upload files를 선택합니다.
1-6. 큰 흰색 업로드 공간에 프로젝트 파일을 드래그합니다.


2. 올려야 하는 파일

프로젝트 폴더에 존재하는 아래 파일을 모두 올립니다.

2-1. .sln
- Visual Studio에서 전체 프로젝트를 여는 파일입니다.

2-2. .csproj
- 프로젝트 설정이 들어 있는 파일입니다.

2-3. 모든 .cs
- 실제 프로그램 코드가 들어 있는 파일입니다.

2-4. 모든 .Designer.cs
- 폼 화면과 버튼의 배치 정보가 들어 있는 파일입니다.

2-5. 모든 .resx
- 폼의 이미지와 리소스 정보가 들어 있는 파일입니다.

2-6. 직접 사용한 이미지, 아이콘, 리소스 폴더

WinForms 폼은 일반적으로 아래 세 파일이 한 세트입니다.

Form1.cs
Form1.Designer.cs
Form1.resx

프로젝트에 Designer.cs나 .resx 파일이 없다면 새로 만들 필요는 없습니다.
현재 프로젝트 폴더에 존재하는 파일만 빠짐없이 올리면 됩니다.


3. 올리지 않는 항목

3-1. .vs 폴더
3-2. bin 폴더
3-3. obj 폴더
3-4. .csproj.user 파일

위 항목들은 Visual Studio에서 자동으로 다시 생성되므로 올리지 않습니다.


4. 작업 제목 작성 및 업로드 완료

4-1. 파일을 올린 후 화면 아래의 Commit changes 영역으로 이동합니다.

4-2. Add files via upload이라고 표시된 첫 번째 입력칸에 작업 제목을 작성합니다.

제목 예시:

로그인 화면 코드 추가
게임 기능 추가
폼 디자인 완성
오류 수정

4-3. 그 아래의 큰 입력칸은 자세한 설명을 적는 곳입니다.
필요하지 않으면 비워도 됩니다.

4-4. Commit directly to 자기 이름 branch가 선택됐는지 확인합니다.

4-5. 초록색 Commit changes 버튼을 누릅니다.

4-6. 자기 이름 브랜치에 업로드한 파일이 보이면 완료
----------------------------------------------------------
*******다른 사람 프로젝트 다운로드하기********

1-1. moble2 저장소에 접속합니다.

1-2. 파일 목록 위쪽의 브랜치 버튼을 누릅니다.

1-3. 다운로드할 사람의 이름 브랜치를 선택합니다.

1-4. 초록색 Code 버튼을 누릅니다.

1-5. 팝업 위쪽에서 Local을 선택합니다.

1-6. Download ZIP을 누릅니다.

1-7. 다운로드된 ZIP 파일의 압축을 풉니다.

------------------------------------------------------------------
**************Visual Studio 2022에서 실행하기****************

2-1. 압축을 푼 폴더를 엽니다.

2-2. 폴더 안의 .sln 파일을 더블클릭합니다.

2-3. Visual Studio 2022가 열릴 때까지 기다립니다.

2-4. 보안 경고가 나오면 신뢰할 수 있는 팀 코드인지 확인한 후 진행합니다.

2-5. Visual Studio 상단의 초록색 실행 버튼이나 F5를 누릅니다.

2-6. 오류 없이 프로그램 창이 나오면 정상입니다.

.sln 파일이 바로 열리지 않으면 Visual Studio 2022에서 아래 순서로 엽니다.

파일 → 열기 → 프로젝트/솔루션 → .sln 파일 선택

----------------------------------------------------------------------------

************3. 팀 작업 규칙*****************

3-1. 각자 자기 이름 브랜치에만 코드를 올립니다.

3-2. test와 main 브랜치에는 직접 올리지 않습니다.

3-3. 각자의 코드를 먼저 test 브랜치에 합쳐 실행합니다.

3-4. 모든 기능이 정상적으로 작동하면 최종본만 main 브랜치에 반영합니다.
